Lot Grabber settings

Save folder

Each lot gets its own subfolder here, with the summary, photos, and JSON side by side. Chrome won't let extensions write to the Downloads root itself, so create or pick a folder inside it, like Downloads/lots.

Not set

Photo analysis

Photos and lot data go straight from this browser to api.anthropic.com. The key is stored in this extension's local storage, which anyone with access to this Chrome profile can read.

Bid math

Max bid = exit − repair × contingency − fees − tax − transport − title − holding − profit. Profit is the larger of the minimum and the percentage of all-in.
